# Автопостинг статей в Яндекс.Дзен

Генерирует статьи по 3500-5000 знаков (тема — "интересные факты") через Claude API,
подбирает к ним фото через Pexels, публикует их на простом сайте (GitHub Pages)
и собирает RSS-ленту в формате, который принимает Дзен. GitHub Actions запускает
генерацию 3 статей дважды в день — в 7:00 и 20:00 по Москве.

## Как это устроено (важно понимать)

Дзен **не берёт статьи "из воздуха"** — по официальным требованиям RSS-лента
должна ссылаться на материалы, реально размещённые на вашем сайте
(https://dzen.ru/help/ru/website/rss-modify.html). Поэтому в проекте есть
мини-сайт (папка `docs/`, отдаётся через GitHub Pages) — туда генератор
складывает HTML-страницы статей, а `feed.xml` просто описывает эти же страницы.

## Шаг 1. Заведите репозиторий

1. Создайте новый репозиторий на GitHub (можно приватный).
2. Залейте в него содержимое этой папки.
3. В настройках репозитория → **Settings → Pages** включите публикацию
   из ветки `main`, папка `/docs`.
4. Ваш сайт будет доступен по адресу `https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПО/`.

## Шаг 2. Получите ключи API

- **Anthropic API key** — https://console.anthropic.com (раздел API Keys).
- **Pexels API key** — https://www.pexels.com/api/ (бесплатно, лимит хватает
  с запасом на 6 статей × 4 фото в день).

## Шаг 3. Добавьте секреты в GitHub

В репозитории: **Settings → Secrets and variables → Actions**

- Вкладка **Secrets**, кнопка New repository secret:
  - `ANTHROPIC_API_KEY` — ваш ключ Anthropic
  - `PEXELS_API_KEY` — ваш ключ Pexels
- Вкладка **Variables**, кнопка New repository variable:
  - `SITE_URL` = `https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПО`

## Шаг 4. Наполните сайт перед подключением к Дзену

Дзен требует, чтобы **при первом подключении лента содержала минимум 10
материалов**, а на сайте было минимум 3 публикации за последний месяц.
Поэтому перед подключением запустите генерацию вручную 3-4 раза:

- В репозитории откройте вкладку **Actions → Generate and publish Zen
  articles → Run workflow** — жмите несколько раз с интервалом в пару минут,
  пока не наберётся 10+ статей в `docs/articles.json`.

(Дальше это будет происходить само по расписанию — 3 статьи в 7:00 и 3 в 20:00 МСК.)

## Шаг 5. Подключите сайт и RSS в Дзене

1. Зайдите в [Студию Дзена](https://dzen.ru/id/editor) под своим каналом.
2. Настройки → раздел **"Дзен для медиа" / "Объединение сайта и канала"**
   (пункт может называться чуть иначе в зависимости от текущего интерфейса) —
   следуйте инструкции: https://dzen.ru/help/ru/website/site-to-channel.html
3. Укажите адрес ленты: `https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПО/feed.xml`
4. Дождитесь модерации подключения (в среднем занимает от нескольких часов
   до пары дней).

## Локальный запуск (для проверки перед деплоем)

```bash
pip install -r requirements.txt
export ANTHROPIC_API_KEY=sk-...
export PEXELS_API_KEY=...
export SITE_URL=https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПО
python scripts/generate.py --count 1
```

Проверьте `docs/articles/*.html` и `docs/feed.xml`.

## Что можно донастроить

- **Темы** — список `TOPIC_POOL` в `scripts/generate.py`. Замените под свою нишу.
- **Модель** — по умолчанию `claude-sonnet-5`; можно сменить на другую доступную модель.
- **Расписание** — в `.github/workflows/publish.yml`, время указано в UTC.
- **Стиль статьи** — правьте промпт внутри функции `generate_article`.

## Ограничения, о которых стоит знать

- Материалы, отправленные через RSS, обновляются в Дзене только в течение 7
  дней после первой загрузки — правки после этого срока нужно вносить вручную
  в Студии.
- Дзен требует **оригинальный** контент: не публикуйте то же самое ещё где-то,
  иначе материал не пройдёт модерацию как неоригинальный.
- За один заход в ленту должно быть не более 500 публикаций — в нашем случае
  это не проблема (в ленте всегда только свежие 2-3 дня).
- Правила и модерация Дзена могут меняться — периодически сверяйтесь с
  https://dzen.ru/help/ru/website/rss-modify.html
